# 1.4 快速上手

本节帮助你在 5 分钟内完成首次配置。

## 第一步：添加供应商

1. 点击主界面右上角的 **+** 按钮
2. 在「预设」下拉框中选择你的供应商
   - 常用预设：智谱 GLM、MiniMax、DeepSeek、Kimi、PackyCode
   - 或选择「自定义」手动配置
3. 填写 **API Key**
4. 点击「添加」

![image-20260108002807657](../../assets/image-20260108002807657.png)

> 💡 **提示**：预设会自动填充端点地址，你只需要填写 API Key。密钥会写入 Windows 凭据管理器，不会保存在数据库或配置文件里。

## 第二步：切换供应商

添加完成后，供应商会出现在列表中。

**方式一：主界面切换**
- 点击供应商卡片的「启用」按钮

**方式二：托盘快速切换**
- 右键系统托盘图标
- 直接点击供应商名称

> ⚠️ **注意**：切换是通过写入用户级环境变量（`HKCU\Environment`）投递凭据的，**已经打开的终端看不到新值，必须重新打开终端**。想立刻使用，可以点击供应商卡片上的「打开终端」，CC Switch 会把变量直接注入到那个终端进程，无需重开。

## 第三步：生效方式

切换供应商后，各 CLI 工具的生效方式：

| 应用 | 生效方式 |
|------|----------|
| Claude Code | 需要重新打开终端（新环境变量才会被读到） |
| Codex | 需要重新打开终端 |
| Pi | 重新打开 Pi 会话即可；Pi 支持多个供应商同时启用 |

> 💡 从 CC Switch 内的「打开终端」启动的终端即时生效，不用重开。

### Claude Code 首次安装提示

如果 Claude Code 首次启动时提示需要**登录**或显示初始化引导，请在 CC Switch 中开启「跳过 Claude Code 初次安装确认」选项：

1. 打开 CC Switch「设置 → 通用」
2. 开启「跳过 Claude Code 初次安装确认」开关
3. 重新启动 Claude Code

![image-20260108002626389](../../assets/image-20260108002626389.png)

> ⚠️ **注意**：此选项会向 `~/.claude.json` 写入 `hasCompletedOnboarding = true`，跳过官方的新手引导流程。

## 验证配置

重开终端后，启动对应的 CLI 工具并输入简单的问题进行测试：

```bash
# Claude Code - 启动后输入测试问题
claude
> 你好，请简单介绍一下自己

# Codex - 启动后输入测试问题
codex
> 你好，请简单介绍一下自己

# Pi - 启动后输入测试问题
pi
> 你好，请简单介绍一下自己
```

如果 AI 能正常回复，说明配置成功。

## 常见问题

### 切换后不生效？

先重开终端。切换时 CC Switch 写入的是用户级环境变量，运行中的终端进程继承的是旧值。若仍不生效，检查 `~/.claude/settings.local.json` 或项目级 `.claude/settings.json` 里是否有 `env.ANTHROPIC_*`——它们会覆盖进程环境变量，CC Switch 不会代改这些文件，只会给出冲突告警。详见 [5.4 环境变量冲突](../5-faq/5.4-env-conflict.md)。

### 找不到预设？

如果你的供应商不在预设列表中，选择「自定义」手动配置。参考 [添加供应商](../2-providers/2.1-add.md) 了解配置格式。

### 如何恢复官方登录？

选择「官方登录」预设（Claude / Codex），重开终端后按 CLI 自身的登录流程操作。CC Switch 不再托管 OAuth 登录，也不会覆盖 Codex `auth.json` 中你自己的 ChatGPT 登录态。
