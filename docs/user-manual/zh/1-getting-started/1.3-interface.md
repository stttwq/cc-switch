## 顶部导航栏

| 序号 | 元素 | 功能说明 |
|------|------|----------|
| ① | Logo | 点击访问 GitHub 项目页 |

| ④ | 功能区 | 当前应用支持的功能入口 |
| ⑤ | 添加按钮 | 添加新供应商 |

### 应用切换器

点击下拉菜单切换当前管理的应用：

- **Claude** - 管理 Claude Code 配置
- **Codex** - 管理 Codex 配置
- **Pi** - 管理 Pi 供应商（可同时启用多个）

切换后，供应商列表会显示对应应用的配置。具体显示哪些应用由设置中的「应用可见性」控制。

### 功能区按钮

| 按钮 | 功能 | 可见条件 |
|------|------|----------|
| Skills | 技能扩展管理 | Claude / Codex / Pi |
| Prompts | 系统提示词管理 | Claude / Codex / Pi |
| MCP | MCP 服务器管理 | Claude / Codex |

## 供应商卡片

每个供应商以卡片形式展示，从左到右依次包含以下元素：

### 卡片元素（从左到右）

| 序号 | 元素 | 图标 | 功能说明 |
|------|------|------|----------|
| ① | 拖拽手柄 | ≡ | 按住上下拖动调整供应商顺序 |
| ② | 供应商图标 | 🔷 | 显示供应商品牌图标，可自定义颜色 |
| ③ | 供应商信息 | - | 名称、备注/端点地址（可点击打开官网） |
| ④ | 启用按钮 | ▶ | 切换为当前使用的供应商 |
| ⑤ | 编辑按钮 | ✏️ | 编辑供应商配置 |
| ⑥ | 复制按钮 | 📋 | 复制供应商（创建副本） |
| ⑦ | 打开终端按钮 | >_ | 仅 Claude：在注入了当前供应商凭据的终端中启动 CLI |
| ⑧ | 删除按钮 | 🗑️ | 删除供应商（当前启用时禁用） |

> 💡 **提示**：操作按钮区域（④-⑧）在鼠标悬停时显示，平时隐藏以保持界面简洁。

卡片上不会显示密钥。已配置过密钥的供应商只会提示「已配置」，密钥值从不回显到界面。

### 按钮详细说明

| 按钮 | 状态变化 | 说明 |
|------|----------|------|
| **启用** | 已启用时显示 ✓ 并禁用 | Pi 供应商为「添加 / 移除」，可与其它 Pi 供应商同时启用 |
| **编辑** | 始终可用 | 打开编辑面板修改配置 |
| **复制** | 始终可用 | 创建供应商副本，名称后缀 `copy` |
| **打开终端** | 始终可用 | 直接注入环境变量启动终端，无需重开终端 |
| **删除** | 当前启用时半透明禁用 | 需先切换到其他供应商才能删除 |

### 卡片状态

| 状态 | 边框颜色 | 说明 |
|------|----------|------|
| **当前启用** | 🔵 蓝色边框 | 当前使用的供应商 |
| **普通状态** | 默认边框 | 未启用的供应商 |
| **需要密钥** | 提示徽标 | 密钥不参与同步与导出，从其它设备还原后需编辑供应商重新输入 API 密钥才能切换 |

## 系统托盘

CC Switch 在系统托盘显示图标，提供快速操作入口。

### 托盘菜单结构

![image-20260108002153668](../../assets/image-20260108002153668.png)

### 菜单功能

| 菜单项 | 功能 |
|--------|------|
| 打开主界面 | 显示主窗口并聚焦 |
| 应用子菜单 | 按 Claude/Codex/Pi 分组的折叠子菜单（如 "Claude · PackyCode"），标题显示当前供应商 |
| 供应商列表 | 在每个子菜单内，点击切换，当前启用的显示勾选标记 |
| 轻量模式 | 勾选框切换，进入/退出仅托盘运行模式 |
| 退出 | 完全退出应用 |

> **注意**：每个托盘子菜单的标题会显示当前供应商名称（如 "Claude · PackyCode"）。没有配置供应商的应用会显示禁用的"(无供应商)"条目。主界面应用可见性仍由设置中的"应用可见性"选项控制。

### 多语言支持

托盘菜单支持四种语言，根据设置自动切换：

| 语言 | 打开主界面 | 退出 |
|------|-----------|------|
| 简体中文 | 打开主界面 | 退出 |
| 繁體中文 | 開啟主介面 | 退出 |
| English | Open main window | Quit |
| 日本語 | メインウィンドウを開く | 終了 |

### 轻量模式

托盘菜单包含 **轻量模式** 切换开关（勾选框）。启用后：

- 主窗口关闭以释放资源
- 应用仅在系统托盘中运行
- 你仍可通过托盘子菜单切换供应商

要退出轻量模式，取消勾选该选项或点击"打开主界面" — 主窗口将被重建并显示。

> ⚠️ **注意**：从托盘切换供应商同样通过用户级环境变量投递，已打开的终端需要重开才能看到新值。需要立刻使用时，用主界面/卡片上的「打开终端」。

### 使用场景

托盘切换供应商无需打开主界面，适合：

- 频繁切换供应商
- 主窗口最小化时快速操作
- 后台运行时管理配置
- 使用轻量模式以最小化资源占用

## 设置页面

设置页面分为三个 Tab：

### 通用 Tab

- 语言设置（简体中文/繁體中文/English/日本語）
- 主题设置（跟随系统/浅色/深色）
- 应用可见性
- Skills 存储位置与同步方式
- 窗口行为（开机自启、关闭行为）
- 终端设置

### 高级 Tab

- 配置目录设置
- 数据导入导出与备份
- 云同步（WebDAV / S3）
- 全局出站代理
- 凭据存储维护

### 关于 Tab

- 版本信息与发布说明
- 本地环境检查（CLI 工具版本与安装/升级）

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + ,` | 打开设置 |
| `Ctrl + F` | 搜索供应商 |
| `Esc` | 关闭弹窗/搜索 |

## 搜索功能

按 `Ctrl + F` 打开搜索框：

- 支持按名称、备注、URL 搜索
- 实时过滤供应商列表
- 按 `Esc` 关闭搜索
