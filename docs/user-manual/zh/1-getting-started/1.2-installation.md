# 1.2 安装指南

## 官方渠道与系统要求

请只从 **[ccswitch.io](https://ccswitch.io)**、**[GitHub Releases](https://github.com/farion1231/cc-switch/releases)** 或项目源码仓库获取 CC Switch。任何要求付费、充值或索取登录凭据的“CC Switch”网站或客户端都不是官方渠道。

| 系统 | 最低版本 | 架构 |
|------|----------|------|
| Windows | Windows 10 及以上 | x64 |

CC Switch 目前只发布 Windows 版本，没有 macOS / Linux 构建。

## 前置要求

### 安装 Node.js

CC Switch 管理的 CLI 工具（Claude Code、Codex、Pi）需要 Node.js 环境。

**推荐版本**：Node.js 18 LTS 或更高版本

1. 访问 [Node.js 官网](https://nodejs.org/)

2. 下载 LTS 版本安装包

3. 运行安装程序，按提示完成安装

4. 验证安装：

 ```bash
 node --version
 npm --version
 ```

### 安装 CLI 工具

#### Claude Code

```bash
npm install -g @anthropic-ai/claude-code

# 国内用户如下载慢，使用镜像源
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

#### Codex

```bash
npm install -g @openai/codex

# 国内用户如下载慢，使用镜像源
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

#### Pi

```bash
npm install -g @earendil-works/pi-coding-agent

# 国内用户如下载慢，使用镜像源
npm install -g @earendil-works/pi-coding-agent --registry=https://registry.npmmirror.com
```

> 💡 **提示**：如果经常遇到下载慢的问题，可以全局设置镜像源：
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## 安装

### 安装包方式

1. 访问 [Releases 页面](https://github.com/farion1231/cc-switch/releases)
2. 下载 `CC-Switch-v{版本号}-Windows.msi`
3. 双击运行安装程序
4. 按提示完成安装

注意：运行安装程序后如果没有任何反应，可以在文件上点击右键，在弹出的菜单中打开 `属性`，`常规`页中的 `安全` 勾选 `解除锁定`

### 绿色版（免安装）

1. 下载 `CC-Switch-v{版本号}-Windows-Portable.zip`
2. 解压到任意目录
3. 运行 `CC-Switch.exe`

## 验证安装

安装完成后，启动 CC Switch：

1. 应用窗口正常显示
2. 系统托盘出现 CC Switch 图标
3. 应用切换器中能看到已启用的受管应用，并能切换到目标应用面板

首次启动时，CC Switch 会把此前以明文保存的密钥自动迁移到 **Windows 凭据管理器**，并提示迁移结果。请确保 Windows 凭据服务正在运行，否则应用会拒绝启动迁移并给出明确错误。

## 升级到新版本

CC Switch 不再有应用内更新提示，也不会在启动时联网检查新版本。升级方式：

1. 打开 [Releases 页面](https://github.com/farion1231/cc-switch/releases)
2. 下载最新版本的 MSI 或 Portable ZIP
3. 覆盖安装（或解压覆盖）到新目录

配置与凭据不会被升级改动。升级前的数据库会自动生成一份 `pre-secrets-migration-*.db` 备份，用于需要时回滚到旧版本。

## 卸载

- 通过「设置 → 应用」卸载
- 或运行安装目录下的卸载程序
- 可选：删除配置目录 `%USERPROFILE%\.cc-switch\`
- 可选：在「凭据管理器」中清理 `cc-switch/` 前缀的条目
