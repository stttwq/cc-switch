# 1.1 软件介绍

## 什么是 CC Switch

CC Switch 是一款 Windows 桌面应用，专为使用 AI 工具的开发者设计。它帮助你统一管理 **Claude Code**、**Codex** 和 **Pi** 的配置。

## 解决什么问题

在日常开发中，你可能会遇到这些痛点：

- **多供应商切换麻烦**：使用不同的 API 供应商（官方、中转服务商），需要手动修改配置文件
- **配置分散难管理**：Claude Code、Codex、Pi 各有独立的配置文件，格式不同
- **密钥容易泄露**：API Key 明文写在配置文件里，容易被截图、贴进聊天窗口或提交进仓库

CC Switch 通过统一的界面解决这些问题。

## 核心功能

### 供应商管理
- 一键切换多个 API 供应商配置
- 支持预设模板，快速添加常用供应商
- 密钥只存 Windows 凭据管理器，通过用户级环境变量投递给 CLI
- Pi 支持多个供应商同时启用

### 扩展功能
- **MCP 服务器**：管理 Model Context Protocol 服务器，扩展 AI 能力
- **Prompts**：管理系统提示词预设，快速切换不同场景
- **Skills**：安装和管理技能扩展
- **会话管理器**：在一处浏览、搜索和恢复历史会话

## 支持的应用

| 应用 | 说明 |
|------|------|
| **Claude Code** | Anthropic 官方的 AI 编程助手 |
| **Codex** | OpenAI 的代码生成工具 |
| **Pi** | Pi 编码代理，支持多供应商同时启用 |

## 支持的平台

- **Windows** 10 及以上（x64）

发布物只有 Windows 安装包（MSI）和绿色版（ZIP），没有 macOS / Linux 版本。

## 技术架构

CC Switch 使用现代化的技术栈构建：

- **前端**：React 18 + TypeScript + Tailwind CSS
- **后端**：Tauri 2 + Rust
- **数据存储**：SQLite（供应商、MCP、Prompts）+ JSON（设备设置）
- **凭据存储**：Windows 凭据管理器（Credential Manager）

这种架构确保了：
- 原生级别的性能
- 密钥值不落在任何文件里
