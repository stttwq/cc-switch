# 5.2 常见问题 FAQ

## 安装问题

### Windows 安装后无法启动

**可能原因**：
- 缺少 WebView2 运行时
- 杀毒软件拦截

**解决方法**：
1. 安装 [Microsoft Edge WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
2. 将 CC Switch 添加到杀毒软件白名单

### 提示「无法访问 Windows 凭据管理器」

CC Switch 把密钥存在 Windows 凭据管理器里；取不到时它会直接失败，不会退回明文存储。

**解决方法**：
1. 确认 Windows「凭据管理器」控制面板能正常打开
2. 确认 `Credential Manager` / 相关系统服务正在运行
3. 若在企业域环境中且凭据随漫游配置文件同步受限，可改为本机持久化
4. 处理后在弹窗里点「重试」；弹窗不提供「跳过」

## 供应商问题

### 切换供应商后不生效

**原因**：CC Switch 通过**用户级环境变量**投递凭据，运行中的终端进程继承的是旧值。

**解决方法**：
- 关闭并重新打开终端（Claude Code / Codex / Pi 都适用）
- 或在 Claude 页签点供应商卡片上的「打开终端」，凭据会直接注入那个终端
- 若重开终端后仍不生效，检查 `~/.claude/settings.local.json` 或项目级 `.claude/settings.json` 里是否有 `env.ANTHROPIC_*` —— 它们会覆盖进程环境变量，详见 [5.4 环境变量冲突](./5.4-env-conflict.md)

### 切换被拒绝，提示需要密钥

**原因**：该供应商没有保存过 API Key，或它是从另一台设备同步 / 导入过来的。

**解决方法**：编辑该供应商，重新输入 API Key（和端点地址）并保存。

> 💡 密钥不参与导出与同步，所以换设备后必须重填——这是设计，不是 bug。

### 提示环境变量冲突

**原因**：用户级环境里已经有一个同名变量，且不是 CC Switch 写的、值也不同。

**解决方法**：在冲突对话框里选择「接管（覆盖）」后重跑切换，或取消切换自行处理。接管后原值会被覆盖且不保留。详见 [5.4 环境变量冲突](./5.4-env-conflict.md)。

### API Key 无效

**检查步骤**：
1. 确认 API Key 正确复制（无多余空格）
2. 确认 API Key 未过期
3. 确认端点地址正确
4. 确认已重开终端，CLI 读到的是新变量

### 如何恢复官方登录

**操作步骤**：
1. 选择「官方登录」预设（Claude / Codex）
2. 点击「启用」
3. 重新打开终端
4. 按照 CLI 工具自身的登录流程操作（如 `codex login`）

> 💡 CC Switch 不再托管 OAuth 登录，也不会覆盖 `~/.codex/auth.json` 里你自己的登录态。

## 数据问题

### 配置丢失

**可能原因**：
- 配置目录被删除
- 数据库损坏

**解决方法**：
1. 检查 `~/.cc-switch/` 目录是否存在
2. 从备份恢复：`~/.cc-switch/backups/`
3. 或从之前导出的配置文件导入

> ⚠️ 数据库丢失不影响凭据管理器里的密钥，但供应商需要重新添加并补全密钥。也可以在「凭据管理器」控制面板里按 `cc-switch/` 前缀人工核对残留条目。

### 导入配置失败

**可能原因**：
- 文件格式错误
- 版本不兼容

**解决方法**：
1. 确认文件是 CC Switch 导出的 SQL 备份文件
2. 检查文件内容是否完整
3. 尝试用文本编辑器打开检查格式

### 导出被拒绝，提示检测到疑似密钥

导出前 CC Switch 会扫描文本做回归护栏。命中说明有异常数据混进了数据库。

**解决方法**：删除可疑供应商后重试；若是旧版本导入带来的明文，导入流程会把它们提取进凭据管理器，重新打开应用后再导出即可。

## 其他问题

### 托盘图标不显示

**Windows**：
- 检查任务栏设置，确保 CC Switch 图标未被隐藏
- 检查「设置 → 通用 → 窗口行为」里是否开启了显示托盘图标

### 界面显示异常

**解决方法**：
1. 尝试切换主题（浅色/深色）
2. 重启应用
3. 删除 `~/.cc-switch/settings.json` 重置设置

### 如何升级到新版本

CC Switch 没有应用内更新功能：不会在启动时检查新版本，也不会提示下载。

**升级方式**：到 [GitHub Releases](https://github.com/stttwq/cc-switch/releases) 下载最新的 Windows 安装包（MSI），覆盖安装即可。配置与凭据不受影响。

## 轻量模式

### 如何进入轻量模式？

从系统托盘菜单切换"轻量模式"。主窗口被关闭，CC Switch 仅作为托盘应用运行。再次切换或点击"打开主界面"即可退出。

### 轻量模式下应用占用更少内存？

是的。轻量模式会销毁主窗口及其 Web 视图，显著减少内存占用，同时保留托盘菜单功能。

## 获取帮助

### 提交 Issue

如果以上方法都无法解决问题：

1. 访问 [GitHub Issues](https://github.com/stttwq/cc-switch/issues)
2. 搜索是否有类似问题
3. 如果没有，创建新 Issue
4. 提供以下信息：
   - Windows 版本
   - CC Switch 版本
   - 问题描述和复现步骤
   - 错误信息（如有）

### 日志文件

CC Switch 的日志位于应用配置目录中。默认配置目录是用户主目录下的 `.cc-switch`；如果你在高级设置中修改过配置目录，请以自定义目录为准。

提交 Issue 时，请按问题类型附上：

- 普通错误与网络问题：`~/.cc-switch/logs/` 中的 `cc-switch.log` 及其轮转文件
- 应用崩溃：`~/.cc-switch/crash.log` 及 `crash.log.1`、`crash.log.2`
- Windows 默认路径为 `C:\Users\<用户名>\.cc-switch\...`

日志按 20 MB 轮转，并保留最近 4 个归档；重启应用不会再清空已有日志。日志不会写入密钥值，但可能包含运行环境信息，公开提交前建议仍先检查内容。
