# 1.2 Installation Guide

## Official Channels and System Requirements

Only download CC Switch from **[ccswitch.io](https://ccswitch.io)**, **[GitHub Releases](https://github.com/farion1231/cc-switch/releases)**, or the project source repository. Any "CC Switch" site or client that asks for payment, top-ups, or login credentials is not official.

| System | Minimum Version | Architecture |
|--------|-----------------|--------------|
| Windows | Windows 10 or later | x64 |

CC Switch currently ships a Windows build only; there are no macOS or Linux builds.

## Prerequisites

### Install Node.js

The CLI tools managed by CC Switch (Claude Code, Codex, Pi) require a Node.js environment.

**Recommended version**: Node.js 18 LTS or higher

1. Visit the [Node.js official website](https://nodejs.org/)

2. Download the LTS version installer

3. Run the installer and follow the prompts

4. Verify installation:

 ```bash
 node --version
 npm --version
 ```

### Install CLI Tools

#### Claude Code

```bash
npm install -g @anthropic-ai/claude-code

# If the download is slow, use a registry mirror
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

#### Codex

```bash
npm install -g @openai/codex

# If the download is slow, use a registry mirror
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

#### Pi

```bash
npm install -g @earendil-works/pi-coding-agent

# If the download is slow, use a registry mirror
npm install -g @earendil-works/pi-coding-agent --registry=https://registry.npmmirror.com
```

> 💡 **Tip**: if slow downloads are a recurring problem, set the mirror globally:
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## Installation

### Installer

1. Visit the [Releases page](https://github.com/farion1231/cc-switch/releases)
2. Download `CC-Switch-v{version}-Windows.msi`
3. Double-click to run the installer
4. Follow the prompts to complete installation

Note: if nothing happens when you run the installer, right-click the file, open `Properties`, and on the `General` tab under `Security` tick `Unblock`.

### Portable Version (No Installation Required)

1. Download `CC-Switch-v{version}-Windows-Portable.zip`
2. Extract to any directory
3. Run `CC-Switch.exe`

## Verify Installation

After installation, launch CC Switch:

1. The app window displays correctly
2. A CC Switch icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

On first launch, CC Switch automatically migrates any previously stored plain-text secrets into **Windows Credential Manager** and reports the result. Make sure the Windows Credential service is running, otherwise the app refuses to start the migration and shows a clear error.

## Upgrading to a New Version

CC Switch no longer shows in-app update prompts and no longer checks for new versions over the network on startup. To upgrade:

1. Open the [Releases page](https://github.com/farion1231/cc-switch/releases)
2. Download the latest MSI or Portable ZIP
3. Install over the existing version (or extract over it)

Upgrading does not touch your configuration or credentials. Before an upgrade, the database is automatically backed up as `pre-secrets-migration-*.db` so you can roll back to the previous version if needed.

## Uninstall

- Uninstall via "Settings > Apps"
- Or run the uninstaller in the installation directory
- Optional: delete the configuration directory `%USERPROFILE%\.cc-switch\`
- Optional: clean up entries prefixed with `cc-switch/` in Credential Manager
