# 2.4 並べ替えと複製

## ドラッグで並べ替え

ドラッグでプロバイダーの表示順序を調整します。

### 操作手順

1. プロバイダーカード左側の **≡** ドラッグハンドルにマウスを合わせる
2. マウスの左ボタンを押し続ける
3. 目的の位置まで上下にドラッグ
4. マウスを離して並べ替え完了

### 並べ替えの用途

- **よく使うものを優先**：よく使うプロバイダーをリストの上部に配置
- **トレイとドロップダウンリストの順序**：トレイのサブメニューや追加/切り替えリストも同じ順序を継承します

## プロバイダーの複製

プロバイダーのコピーを素早く作成します。以下のような場面に適しています：

- 既存の設定をベースにバリエーションを作成
- 現在の設定をバックアップ
- テスト用の設定を作成


### 操作手順

1. プロバイダーカードにマウスをホバーして操作ボタンを表示
2. 「複製」ボタンをクリック
3. 名前に `copy` が付加されたコピーが自動作成
4. コピーを編集して設定を変更

### コピーされる内容

コピーは設定のコピーを作成します。以下を含みます：

| 内容 | コピーされるか |
|------|----------|
| 名前 | コピーされる（`copy` が付加） |
| 設定 | コピーされる（鍵とエンドポイントアドレスは含まない） |
| Web サイトリンク | コピーされる |
| アイコンと色 | コピーされる |
| 並び順の位置 | 元のプロバイダーの下に挿入 |

> ⚠️ **注意**：API key とエンドポイントアドレスは Windows 資格情報マネージャにあり、プロバイダー ID 単位で紐付いているため、複製には**引き継がれません**。コピー作成後、有効化の前にそれを編集して鍵を補完する必要があります。

### コピー後の編集

コピー完了後、通常は以下を変更します：

1. **名前**：意味のある名前に変更
2. **API Key**：必須。コピーには鍵が含まれません
3. **エンドポイントアドレス**：同ように入力し直しが必要です

## プロバイダーの削除

### 操作手順

1. プロバイダーカードにマウスをホバーして操作ボタンを表示
2. 「削除」ボタンをクリック
3. 削除を確認

### 削除の確認

削除前に確認ダイアログが表示され、以下が表示されます：

- プロバイダー名
- 削除後は元に戻せないという注意

### 削除の制限

- **現在有効なプロバイダー**：削除可能ですが、先に他のプロバイダーに切り替えることをお勧めします

### 削除時に合わせてクリーンアップされるもの

- そのプロバイダーに関する Windows 資格情報マネージャ内のエントリ（API key、エンドポイントアドレス、機密環境変数）
- CC Switch が書き込んだユーザーレベルの環境変数（その後 `WM_SETTINGCHANGE` をブロードキャスト）

他で自分で設定した同名変数には触れません。資格情報エントリの削除に失敗した場合は、警告を記録するだけで削除をブロックしません。「設定 → 詳細 → 資格情報マネージャのメンテナンス」で残りを整理できます。
