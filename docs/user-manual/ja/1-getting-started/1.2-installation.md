# 1.2 インストールガイド

## 公式チャネルとシステム要件

CC Switch は **[ccswitch.io](https://ccswitch.io)**、**[GitHub Releases](https://github.com/farion1231/cc-switch/releases)**、またはプロジェクトのソースリポジトリからのみ入手してください。支払い、チャージ、ログイン情報の入力を求める「CC Switch」サイトやクライアントは公式ではありません。

| システム | 最低バージョン | アーキテクチャ |
|------|----------------|----------------|
| Windows | Windows 10 以上 | x64 |

CC Switch は現状 Windows 版のみ公開しており、macOS / Linux ビルドはありません。

## 前提条件

### Node.js のインストール

CC Switch が管理する CLI ツール（Claude Code、Codex、Pi）には Node.js 環境が必要です。

**推奨バージョン**：Node.js 18 LTS 以上

1. [Node.js 公式サイト](https://nodejs.org/) にアクセス

2. LTS バージョンのインストーラーをダウンロード

3. インストーラーを実行し、指示に従ってインストール

4. インストールの確認：

 ```bash
 node --version
 npm --version
 ```

### CLI ツールのインストール

#### Claude Code

```bash
npm install -g @anthropic-ai/claude-code

# ダウンロードが遅い場合はミラーソースを使用
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

#### Codex

```bash
npm install -g @openai/codex

# ダウンロードが遅い場合はミラーソースを使用
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

#### Pi

```bash
npm install -g @earendil-works/pi-coding-agent

# ダウンロードが遅い場合はミラーソースを使用
npm install -g @earendil-works/pi-coding-agent --registry=https://registry.npmmirror.com
```

> 💡 **ヒント**：ダウンロードが遅いことが頻発する場合は、グローバルにミラーソースを設定できます：
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## インストール

### インストーラー方式

1. [Releases ページ](https://github.com/farion1231/cc-switch/releases) にアクセス
2. `CC-Switch-v{バージョン}-Windows.msi` をダウンロード
3. インストーラーをダブルクリックして実行
4. 指示に従ってインストール

注意：インストーラーを実行しても反応がない場合は、ファイルを右クリックして `プロパティ` を開き、「一般」ページにある `セキュリティ` の `許可する (Unblock)` にチェックを入れてください。

### ポータブル版（インストール不要）

1. `CC-Switch-v{バージョン}-Windows-Portable.zip` をダウンロード
2. 任意のディレクトリに展開
3. `CC-Switch.exe` を実行

## インストールの確認

インストール完了後、CC Switch を起動します：

1. アプリウィンドウが正常に表示される
2. システムトレイに CC Switch のアイコンが表示される
3. アプリ切り替えに有効化された管理対象アプリが表示され、目的のアプリパネルへ切り替えられる

初回起動時、CC Switch はそれ以前に平文で保存されていた鍵を自動的に **Windows 資格情報マネージャ** へ移行し、結果を表示します。Windows の資格情報サービスが起動していることを確認してください。停止している場合、アプリは移行を開始せず明確なエラーを表示します。

## 新しいバージョンへのアップグレード

CC Switch にはアプリ内のお知らせも、起動時の新規バージョンチェックもありません。アップグレード方法：

1. [Releases ページ](https://github.com/farion1231/cc-switch/releases) を開く
2. 最新バージョンの MSI または Portable ZIP をダウンロード
3. 上書きインストール（または展開して上書き）する

設定や認証情報はアップグレードによって変更されません。アップグレード前にデータベースは `pre-secrets-migration-*.db` というロールバック用バックアップを自動生成し、自動的に削除されることはありません。

## アンインストール

- 「設定 → アプリ」からアンインストール
- またはインストールディレクトリのアンインストーラーを実行
- オプション：設定ディレクトリ `%USERPROFILE%\.cc-switch\` を削除
- オプション：「資格情報マネージャ」で `cc-switch/` プレフィックスのエントリを削除
