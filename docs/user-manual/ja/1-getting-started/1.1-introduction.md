# 1.1 ソフトウェア紹介

## CC Switch とは

CC Switch は Windows デスクトップアプリケーションで、AI ツールを使用する開発者向けに設計されています。**Claude Code**、**Codex**、**Pi** の設定を統一的に管理できます。

## どのような問題を解決するか

日常の開発で、以下のような課題に直面することがあります：

- **複数プロバイダーの切り替えが面倒**：異なる API プロバイダー（公式、中継サービスなど）を使用する際、設定ファイルを手動で変更する必要がある
- **設定が分散して管理しづらい**：Claude Code、Codex、Pi がそれぞれ独立した設定ファイルを持ち、フォーマットも異なる
- **鍵が漏洩しやすい**：API key を設定ファイルに平文で書いていると、スクリーンショットやチャットへの貼り付け、リポジトリへのコミットで漏れる可能性がある

CC Switch は統一されたインターフェースでこれらの問題を解決します。

## 主要機能

### プロバイダー管理
- ワンクリックで複数の API プロバイダー設定を切り替え
- プリセットテンプレートで一般的なプロバイダーを素早く追加
- 鍵は Windows 資格情報マネージャのみ保存し、ユーザーレベルの環境変数経由で CLI に供給
- Pi は複数プロバイダーの同時有効化に対応

### 拡張機能
- **MCP サーバー**：Model Context Protocol サーバーを管理し、AI の機能を拡張
- **Prompts**：システムプロンプトのプリセットを管理し、さまざまなシーンで素早く切り替え
- **Skills**：スキル拡張のインストールと管理
- **セッションマネージャー**：履歴セッションを一括して閲覧・検索・再開

## 対応アプリケーション

| アプリ | 説明 |
|------|------|
| **Claude Code** | Anthropic 公式の AI プログラミングアシスタント |
| **Codex** | OpenAI のコード生成ツール |
| **Pi** | Pi コーディングエージェント。複数プロバイダーの同時有効化に対応 |

## 対応プラットフォーム

- **Windows** 10 以上（x64）

公開されているのは Windows インストーラ（MSI）とポータブル版（ZIP）のみで、macOS / Linux 版はありません。

## 技術アーキテクチャ

CC Switch はモダンな技術スタックで構築されています：

- **フロントエンド**：React 18 + TypeScript + Tailwind CSS
- **バックエンド**：Tauri 2 + Rust
- **データストレージ**：SQLite（プロバイダー、MCP、Prompts）+ JSON（デバイス設定）
- **認証情報ストレージ**：Windows 資格情報マネージャ（Credential Manager）

このアーキテクチャにより：
- ネイティブレベルのパフォーマンス
- 鍵の値がファイル上に残らない
